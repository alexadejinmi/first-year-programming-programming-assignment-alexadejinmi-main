# Explore & create: A Square Grid

This is a brand-new sketch, not a copy of an existing one — `index.html`,
`sketch.js` and `style.css` are already here, set up the same way as the
numbered sketches. Edit `sketch.js` directly.

Draw a grid of squares that tiles the whole canvas, each filled with its
own random colour. Use a `for` loop nested inside another `for` loop — the
outer loop stepping down the rows, the inner loop stepping across the
columns of each row — so every row/column combination gets exactly one
square. Pick a square size that divides the canvas evenly (e.g. 40 pixels,
since both 640 and 360 divide evenly by 40).

Commit when you're done:

```
git commit -m "10-square-grid explore & create: done"
```
