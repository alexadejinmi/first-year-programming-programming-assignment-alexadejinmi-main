# Explore & create

Each exercise from an "Explore & create" section (see the relevant
sketch's tutorial page) gets its own folder here, named `NN-slug/` —
`NN` is the sketch it follows, `slug` names the exercise itself.

There's no existing sketch to copy for these — each folder starts as a
brand-new, blank sketch (`index.html`, `sketch.js`, `style.css`), and its
own README.md has the full task text, including which existing sketch's
pattern to start from.

Commit when a folder's task is done, naming the folder:

```
git commit -m "05-color-swatches explore & create: done"
```
