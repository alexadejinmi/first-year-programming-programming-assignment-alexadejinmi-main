# Explore & create: A Line Grid

This is a brand-new sketch, not a copy of an existing one — `index.html`,
`sketch.js` and `style.css` are already here, set up the same way as the
numbered sketches. Edit `sketch.js` directly.

Draw a series of horizontal lines, 10 pixels apart, running down the whole
canvas, and a series of vertical lines, 10 pixels apart, running across the
whole canvas — so the result looks like a sheet of graph paper. Use one
`for` loop for the horizontal lines and a separate `for` loop for the
vertical lines; drive each loop from `width`/`height` rather than a
hard-coded number of lines, so the grid still fills the canvas exactly if
the canvas size changes.
