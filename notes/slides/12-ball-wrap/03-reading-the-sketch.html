12 — Wrapping Around the Edges

Reading the sketch

move() {
    this.x = (this.x + this.vx + width) % width;    // was: this.x += this.vx;
    this.y = (this.y + this.vy + height) % height;  // was: this.y += this.vy;
}

Everything else in the sketch — the Ball class's display(), the array of five balls, the draw() loop calling .move() then .display() — is unchanged from sketch 11. Only the two lines inside move() are different: plain += movement is replaced by the modulo formula, so a ball that steps past one edge reappears at the opposite edge instead of drifting off-canvas.
