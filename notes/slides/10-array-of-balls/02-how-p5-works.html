10 — An Array of Balls

How p5 works

  • Everything here still runs inside setup() — called once. The for loop that builds and displays all five balls is entirely inside setup(), and p5 only calls setup() once, at the start. So all five balls are drawn a single time when the sketch loads, and then nothing further happens — draw() is empty, exactly as in sketch 01. This is the setup-once/draw- repeatedly split from sketch 01, seen concretely from the "only setup runs" side.
  • text() is a drawing call, textAlign() is a style call. text(str, x, y) draws a string onto the canvas at a given position — a drawing call just like circle(), and it uses whatever fill colour is currently set, exactly the same way circle() does. textAlign(CENTER, CENTER) is a style call (like noStroke() or fill()): it doesn't draw anything itself, it sets how later text() calls position their text relative to the (x, y) they're given — here, centred on that point rather than starting from it.
