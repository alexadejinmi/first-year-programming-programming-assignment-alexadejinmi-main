03 — Click to Draw

Reading the sketch

function setup() {
    createCanvas(640, 360);
    background(230);          // paint once at the start
}

function draw() {
    // still called ~60/sec by p5, but empty — nothing happens automatically
}

function mousePressed() {
    // p5 calls this once, exactly when the mouse button is pressed
    noStroke();
    fill(255, 0, 100, 150);
    circle(mouseX, mouseY, 150);   // stamp a circle at the click position
}

function keyPressed() {
    // p5 calls this once, exactly when a key is pressed
    background(230);               // paint over everything — clears the canvas
}

The drawing code has moved out of draw() (now empty) and into mousePressed(), so a circle is stamped only on click, at wherever mouseX/mouseY happen to be at that instant — not tracked continuously the way sketch 02 did. A new keyPressed() function clears the canvas on any key press by drawing over it with background(), exactly the same call setup() used once in sketch 01.
