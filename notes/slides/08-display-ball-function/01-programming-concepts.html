08 — A displayBall() Function

Programming concepts

Passing an object into a function as a parameter

function displayBall(b) {
    noStroke();
    fill(b.col);
    circle(b.x, b.y, b.diameter);
}

displayBall() takes a single parameter, b, and expects it to be a ball-shaped object — one with x, y, diameter and col properties. Calling displayBall(ball) passes the whole object in one argument; inside the function, b refers to that same object, and its properties are read via dot notation exactly as ball.x etc. were read directly in mousePressed() before.

Functions that operate on a passed-in object

Sketch 07's createBall() built an object and handed it back. displayBall() does the opposite kind of job: given an object that already exists, it does something with it — here, draws it — without needing to know where that object came from or what it's called outside the function. This is a common and useful shape: a function that operates on whatever object it's given, rather than reaching for a specific global variable by name. It's what makes displayBall() reusable for any ball-shaped object, not just the one currently stored in ball.
