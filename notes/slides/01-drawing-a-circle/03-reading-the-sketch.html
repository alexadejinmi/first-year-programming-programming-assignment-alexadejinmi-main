01 — Drawing a Circle

Reading the sketch

function setup() {
    createCanvas(640, 360);   // make a 640×360 canvas
    background(230);          // paint it a light grey
    noStroke();                // shapes drawn from here on have no outline
    fill(255, 0, 100, 150);   // shapes drawn from here on are filled pink, semi-transparent
    circle(320, 180, 150);    // draw a circle: centred (320, 180), 150px diameter
}

function draw() {
    // p5 calls this ~60 times a second, but there's nothing here — so nothing happens
}

Everything happens once, inside setup(), when the sketch loads: a canvas is created, painted grey, and one circle is stamped in the middle. draw() exists (p5 expects it to) but is empty, so the picture never changes after that.
