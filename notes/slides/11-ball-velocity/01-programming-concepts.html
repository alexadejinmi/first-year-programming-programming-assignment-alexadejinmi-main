11 — Ball Velocity

Programming concepts

Extra state: velocity

constructor(x, y, vx, vy, d, c) {
    this.x = x;
    this.y = y;
    this.vx = vx;
    this.vy = vy;
    ...
}

Two new properties, vx and vy, are added alongside the position and size properties Ball already had. They represent velocity — how far the ball moves on the x-axis and y-axis every time it updates, not its current position. Each ball is constructed with its own vx/vy arguments, so every ball in the array can move at a different speed and in a different direction, exactly the same way each already has its own position, size and colour.

A method that changes its own object's state

move() {
    this.x += this.vx;
    this.y += this.vy;
}

move() is a new method (from sketch 09: a function that lives inside a class and uses this) whose whole job is to update the object's own properties. Calling ball.move() changes that particular ball's x/y — it doesn't return anything or draw anything, unlike display(). This is a common shape for methods: some describe an object (display()), others change it (move()).

Compound assignment: +=

this.x += this.vx; is shorthand for this.x = this.x + this.vx; — take the current value, add something to it, and store the result back in the same place. += is one of several compound assignment operators (others include -=, *=, /=) that combine "compute a new value from the old one" and "store it" into a single step.
