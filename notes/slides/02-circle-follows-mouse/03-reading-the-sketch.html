02 — Circle Follows the Mouse

Reading the sketch

function setup() {
    createCanvas(640, 360);   // runs once — just makes the canvas
}

function draw() {
    background(230);                  // erase last frame, every frame
    console.log(mouseX, mouseY);      // print the mouse position to the console
    noStroke();
    fill(255, 0, 100, 150);
    circle(mouseX, mouseY, 150);      // draw the circle at the current mouse position
}

setup() now does nothing but create the canvas. All the drawing that sketch 01 did once, in setup(), has moved into draw() — and the fixed position (320, 180) has been replaced with (mouseX, mouseY). Because draw() runs ~60 times a second and reads the mouse position fresh each time, the circle appears to follow the mouse continuously, even though each individual frame just draws one circle in one place, exactly like sketch 01 did.
