02 — Circle Follows the Mouse

How p5 works

  • draw() runs continuously — the render loop. p5 calls draw() automatically and repeatedly, about 60 times a second, for as long as the sketch runs. That's the mechanism behind all animation: nothing inside draw() loops by itself, p5 just keeps calling the whole function again and again, each call is one frame.
  • background() must run every frame to erase the last one. The canvas is a persistent bitmap (from sketch 01) — nothing clears itself automatically. Because draw() now runs 60 times a second, background(230) has to be the first thing it does each time; otherwise every frame's circle would be drawn on top of the last, and circles would pile up across the screen as the mouse moves.
  • mouseX and mouseY are kept current by p5. These aren't ordinary variables that the sketch sets — p5 updates them continuously in the background to match the real mouse position, so reading mouseX/mouseY anywhere inside draw() always gives the mouse's position right now, at that frame.
  • mouseX/mouseY are just two of many system variables. p5 keeps a whole set of these — ordinary-looking variables that p5 itself updates continuously, rather than values the sketch ever assigns. A few worth knowing exist, even before there's a reason to use them all:
System variable What it holds
width Width (in pixels) of the sketch window
height Height (in pixels) of the sketch window
frameCount Number of frames processed since the sketch started
frameRate Rate frames are currently being processed, per second
displayWidth Width (in pixels) of the entire screen
displayHeight Height (in pixels) of the entire screen
key The most recent key pressed on the keyboard
keyCode The numeric code for the key pressed on the keyboard
keyIsPressed true/false — is a key currently pressed?
mouseIsPressed true/false — is the mouse currently pressed?
mouseButton Which mouse button is pressed — LEFT, RIGHT, or CENTER

width/height already appeared in sketch 01; frameCount shows up in this sketch's exercises below; the rest aren't used anywhere in these 13 sketches, but they're one line away in the p5 reference the moment a sketch needs them.
