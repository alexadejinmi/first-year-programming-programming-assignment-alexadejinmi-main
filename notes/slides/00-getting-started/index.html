00 — Getting Started: How Computer Graphics Work

This file comes before sketch 01. It has no sketch.js of its own — instead, it sets up the vocabulary that every sketch from 01-drawing-a-circle onward assumes you already have: what a pixel is, what the canvas actually is, how positions are measured on it, and how colour is represented as numbers. None of this is p5-specific — it's how computer graphics work in general — but it's the ground everything else in this module stands on.

On this page

  • Pixels: pictures made of tiny squares
  • The canvas: your drawing surface
  • The coordinate system
  • Drawing shapes
  • Drawing modes: CORNER vs CENTER
  • Colour models: RGB
  • CMYK: colour on paper
  • HSB and HSL: colour by hue, saturation and brightness
  • Grayscale colour
  • Transparency: the alpha channel
