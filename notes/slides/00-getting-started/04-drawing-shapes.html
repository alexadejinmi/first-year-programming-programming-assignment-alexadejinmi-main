00 — Getting Started: How Computer Graphics Work

Drawing shapes

p5 provides a small set of built-in functions for drawing basic shapes, each taking the numbers it needs as arguments — a position, plus whatever sizes define that shape:

point(50, 50);                    // a single point, at (x, y)
line(50, 50, 200, 150);           // a straight line, from (x1, y1) to (x2, y2)
rect(50, 50, 120, 80);            // a rectangle: top-left corner (x, y), then width, height
circle(200, 200, 100);            // a circle, centred at (x, y), with diameter d
ellipse(200, 200, 100, 60);       // an ellipse, centred at (x, y), with width, height
triangle(50, 150, 100, 50, 150, 150); // a triangle, from three (x, y) corner points

Two things are worth noticing across all of these. First, every shape is defined entirely by numbers — there's no "circle object" being handed to circle(), just plain arguments. Second, the meaning of those numbers is different for every function: rect()'s first two numbers are a corner, circle()'s first two numbers are a centre, and there's no way to tell which is which just by looking at a bare list of numbers — you have to know (or look up) what each function expects.
